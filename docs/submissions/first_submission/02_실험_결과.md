# 첫 번째 제출 모델의 실험 결과

## 1. 결과 해석 기준

이 문서는 첫 번째 공개 제출 이미지 `mal2026-r0-ensemble:20260731-001`을 구성하는
모델 선택 결과와 제출 검증 결과를 집계한다.

점수 모델의 주 지표는 내용·조직·표현 세 축의 산술 평균이다.

- RMSE: 낮을수록 좋음
- tie-aware Spearman: 높을수록 좋음
- rationale judge: 5점 척도, 높을수록 좋음

400개 검증 글은 개발 과정에서 반복적으로 사용되었으므로 아래 수치는 모두
**개발용 검증 결과**다. 대회 hidden test 성능으로 해석하지 않는다.

## 2. 근거 생성 모델 결과

### 2.1 SFT 대비 RLAIF-GRPO

고정된 Qwen-v6 judge로 400개 검증 글을 다섯 프롬프트 형식과 열 번의 반복으로
평가했다. 표의 delta는 같은 기반 모델의 SFT 대비 변화다.

| 기반 모델 | SFT macro | GRPO `all5` delta | GRPO `random1` delta |
| --- | ---: | ---: | ---: |
| Midm-2.0-Base | 3.867967 | +0.306317 | +0.321133 |
| A.X-4.0-Light | 3.766183 | +0.417883 | **+0.420850** |
| Phi-4-mini | 3.049750 | +0.768150 | +0.668567 |

A.X `random1`의 최종 macro는 4.187033이었다. judge 기준 전체 bundle 순위에서는
Midm `random1` 4.189100에 이어 2위였지만, 이후 점수 회귀 결합 실험에서 더 낮은
RMSE를 만들었다.

### 2.2 상위 세 근거 출처의 점수 회귀 비교

각 근거 출처를 별도 Qwen2.5-7B 회귀기에 입력한 결과다. 근거를 서로 합치거나
앙상블하지 않았다.

| 근거 출처 | 내용 RMSE | 조직 RMSE | 표현 RMSE | macro RMSE | macro Spearman |
| --- | ---: | ---: | ---: | ---: | ---: |
| Midm `random1` | 0.592465 | 0.774760 | 0.632834 | 0.666686 | 0.489959 |
| **A.X `random1`** | **0.590273** | 0.769708 | **0.629532** | **0.663171** | **0.497492** |
| A.X `all5` | 0.591685 | **0.769705** | 0.634594 | 0.665328 | 0.489690 |

이 결과로 A.X `random1`이 최종 점수 모델의 고정 근거 생성기로 선택되었다.

## 3. Qwen3-Embedding 점수 모델 결과

### 3.1 초기화 비교

두 모델은 같은 2,000개 학습 글, 같은 A.X `random1` 근거, 같은 학습 스케줄을
사용했다.

| 초기화 | 내용 RMSE / Spearman | 조직 RMSE / Spearman | 표현 RMSE / Spearman | macro RMSE / Spearman |
| --- | ---: | ---: | ---: | ---: |
| 공개 Qwen3-Embedding base | 1.884778 / -0.103866 | 2.029515 / 0.008927 | 2.273013 / 0.001607 | 2.062436 / -0.031111 |
| **AI-Hub 48,016건 warm start** | **0.531378 / 0.582048** | **0.710936 / 0.578077** | **0.531244 / 0.604543** | **0.591186 / 0.588222** |
| 이전 Qwen2.5 근거 회귀 기준선 | 0.590273 / 0.543862 | 0.769708 / 0.580551 | 0.629532 / 0.368061 | 0.663171 / 0.497492 |

AI-Hub warm start는 직접 비교 가능한 Qwen2.5 기준선보다 macro RMSE가 0.071985,
상대적으로 10.85% 낮았다. 공개 Qwen3 초기화는 동일한 384-update 스케줄에서
유효한 점수 모델을 학습하지 못했다.

### 3.3 최종 R0 예측 앙상블

| 모델 | 내용 RMSE | 조직 RMSE | 표현 RMSE | macro RMSE | macro Spearman |
| --- | ---: | ---: | ---: | ---: | ---: |
| **R0 epoch 1~4 예측 평균** | **0.502760** | **0.683891** | **0.488231** | **0.558294** | **0.644196** |
| 단일 epoch 3 | 0.512864 | 0.695580 | 0.499289 | 0.569245 | 0.625288 |
| 다중 근거 입력 ablation | - | - | - | 0.591079 | - |
| full AI-Hub 후 rationale LoRA, epoch 4 | 2.578675 | 2.685845 | 2.973646 | 2.746055 | 정의 불가 |

예측 앙상블은 단일 epoch 3보다 macro RMSE를 0.010951 낮췄다. 네 모델의 가중치를
평균한 것이 아니라, 각 모델의 연속 예측값을 축별로 균등 평균했다.

### 3.4 제출 시점의 연속·정수 점수 지표

| 지표 | 결과 |
| --- | ---: |
| 연속 점수 macro RMSE | **0.5582937519** |
| 연속 점수 macro Spearman | **0.6441959865** |
| 정수 점수 macro RMSE | **0.6158981882** |
| 정수 점수 macro Spearman | **0.5681974395** |

정수 점수는 연속 앙상블 예측을 `[1, 5]`로 자른 뒤 `floor(x + 0.5)` 방식으로
half-up 반올림하여 얻었다. 검증 label에 맞춘 별도 threshold나 calibration은
사용하지 않았다.

## 4. 최종 DPO 근거 모델 결과

### 4.1 학습 데이터 집계

| 항목 | 값 |
| --- | ---: |
| train-only 생성 그룹 | 6,000 |
| 생성 후보 | 24,000 |
| 의미적 오류로 교체한 후보 | 90 |
| 전체 동점으로 제외한 그룹 | 3,230 |
| 최종 DPO 선호쌍 | 2,770 |
| DPO 업데이트 | 174 |

### 4.2 고정 검증 비교

| 근거 모델 | macro (/5) | 평균 합계 (/60) | 60/60 비율 |
| --- | ---: | ---: | ---: |
| SFT 기준선 | 4.9839583 | 59.8075 | 89.25% |
| **Bundle DPO** | **4.9877083** | **59.8525** | **93.00%** |

쌍별로 DPO가 37개 글에서 이겼고, 340개는 동점, 23개는 패배했다. DPO와 SFT의
평균 차이는 60점 만점에 +0.045였으며 양측 exact sign-test p-value는 0.092461이었다.
따라서 DPO를 수치상 최종 근거 모델로 선택했지만, 개선 효과가 크거나 통계적으로
강하게 확립되었다고 주장하지 않는다.

### 5.2 모델 포함 GPU/API 스모크

이미지 자체를 별도 명령 없이 GPU0에서 시작했다. health는 98초 후 준비되었으며
`/v1/models`는 `mal2026-r0-ensemble-v1`을 반환했다.

| 합성 요청 | 지연 시간 | 출력 검증 |
| --- | ---: | --- |
| 짧은 입력 | 23.374초 | 점수 3/3/4, 세 근거 모두 비어 있지 않음, strict JSON |
| 긴 입력 | 16.849초 | 점수 3/3/4, 2,048 토큰 우측 절단 경로 통과, strict JSON |

- 관측된 H100 최대 메모리: 52,577 MiB
- 테스트 후 소유 컨테이너 제거 및 GPU0 메모리 반환 확인
- Docker Hub push 후 index, manifest, config와 36개 layer를 익명 접근으로 확인
- 공개 Hugging Face 저장소의 22개 custom artifact도 익명 조회로 확인

### 5.3 L40S 용량 근사 검증

실제 L40S는 사용할 수 없었으므로 H100의 vLLM 메모리 예약을 대표 L40S보다 조금
작게 제한하여 보수적인 용량 근사를 수행했다.

- 전체 2회 근거 생성 + 4회 점수 추론 요청 통과
- 관측 peak: 36,677 MiB
- 대표 L40S 46,068 MiB 대비 여유: 9,391 MiB

이는 용량 적합성을 지지하지만, L40S 고유 커널 호환성과 지연 시간을 직접 검증한
결과는 아니다.

## 7. 결론

첫 번째 제출의 핵심 성과는 서로 역할이 다른 모델을 결합한 데 있다.

1. 점수를 보지 않는 A.X 근거 생성기가 글의 질적 특징을 구조화한다.
2. AI-Hub warm start Qwen3-Embedding의 네 초기 epoch 모델이 각자 연속 점수를 낸다.
3. 네 예측을 균등 평균하여 단일 체크포인트보다 RMSE와 Spearman을 모두 개선한다.
4. 예측된 정수 점수만을 조건으로 별도 DPO 모델이 제출용 한국어 근거를 작성한다.

다만 모든 수치는 이미 노출된 400개 개발 검증 집합에서 얻었고, 최종 결합의
hidden-test 성능이나 인간 근거 품질을 직접 보장하지 않는다.
