# 첫 번째 제출 모델: 방법론과 결과 요약

## 1. 방법론

첫 번째 제출 모델은 근거 생성 모델과 점수 예측 모델을 결합한 파이프라인이다.
내용, 조직, 표현의 세 평가 영역을 각각 1점부터 5점까지 예측하고, 각 점수에 대한
한국어 평가 근거를 함께 출력한다.

### 1.1 평가 근거 생성

학습용 평가 근거는 A.X-4.0-Light가 생성한 것이 아니라 GPT API의
`gpt-5.6-terra`가 생성했다. 학습 글 2,000개마다 세 후보를 생성하여 총 6,000개의
학습 예제를 만들었고, 각 후보의 내용, 조직, 표현별 진단문을 정답 근거로 사용했다.
GPT가 함께 생성한 후보 점수는 SFT 입력이나 정답으로 사용하지 않았다.

A.X-4.0-Light는 이 GPT 생성 근거를 모방하도록 LoRA SFT되었다. 이후 별도의 LLM
평가 모델이 부여한 품질 점수를 보상으로 사용하는 GRPO 학습을 추가로 수행했다.
실제 추론에서는 이렇게 학습된 A.X 모델이 글쓰기 문항과 학생 글만 읽고 내용,
조직, 표현에 대한 근거를 생성하며, 실제 점수나 정답은 제공받지 않는다.

### 1.2 점수 예측

Qwen3-Embedding-8B 모델이 글쓰기 문항, 학생 글, 앞 단계에서 생성한 세 영역의
근거를 함께 입력받아 내용, 조직, 표현의 연속 점수를 예측한다.

점수 모델은 먼저 AI-Hub의 인간 피드백 데이터 48,016건으로 학습한 상태에서
시작하고, 이후 대회 학습 데이터 2,000건으로 추가 학습했다. 모델의 마지막 유효
토큰 임베딩을 정규화한 뒤 세 개의 점수를 출력하는 선형 회귀 헤드에 입력했으며,
학습에는 평균제곱오차를 사용했다.

### 1.3 체크포인트 앙상블

추가 학습 과정에서 저장한 1~4 epoch 모델이 같은 입력을 각각 독립적으로 평가한다.
네 모델의 연속 예측값을 영역별로 단순 평균한 뒤 1점에서 5점 사이로 제한하고,
가장 가까운 정수로 반올림한다.

검증 데이터에 맞춘 별도의 앙상블 가중치, 보정식 또는 점수 임계값은 사용하지 않았다.

### 1.4 최종 근거 작성

점수가 결정되면 별도의 A.X-4.0-Light DPO 모델이 글과 예측 점수를 바탕으로 최종
한국어 근거를 작성한다. 이때 모델에는 정답 점수가 아니라 앞 단계에서 예측한 점수만
제공한다.

최종 출력은 내용, 조직, 표현별 정수 점수와 근거를 포함하는 하나의 JSON 객체다.

## 2. 주요 결과

### 2.1 연속 점수 예측

| 모델 | 내용 RMSE | 조직 RMSE | 표현 RMSE | 평균 RMSE | 평균 Spearman |
| --- | ---: | ---: | ---: | ---: | ---: |
| 단일 3 epoch 모델 | 0.512864 | 0.695580 | 0.499289 | 0.569245 | 0.625288 |
| **1~4 epoch 예측 앙상블** | **0.502760** | **0.683891** | **0.488231** | **0.558294** | **0.644196** |

1~4 epoch 예측 앙상블은 가장 좋은 단일 체크포인트보다 평균 RMSE를 0.010951
낮췄고 Spearman도 개선했다. 세 영역 중에서는 조직 점수의 오차가 가장 컸다.

### 2.2 정수 점수 예측

| 지표 | 결과 |
| --- | ---: |
| 평균 RMSE | 0.615898 |
| 평균 Spearman | 0.568197 |

### 2.3 최종 근거 품질

최종 DPO 근거 모델은 5점 척도의 LLM 평가에서 평균 4.987708점을 기록했다.
기준 SFT 모델의 4.983958점보다 높았지만 차이는 작았으며, 대부분의 평가 글에서
두 모델이 동점을 기록했다.

### 2.4 제출 실행 검증

전체 모델을 하나의 Docker 이미지에 포함하여 외부 모델 다운로드 없이 실행했다.
단일 GPU에서 서버 시작, 상태 확인, 모델 목록 조회, 짧은 글과 긴 글의 점수·근거
생성을 모두 완료했다. 두 입력 모두 세 영역의 정수 점수와 비어 있지 않은 한국어
근거를 올바른 JSON 형식으로 반환했다.

## 3. 결론

첫 번째 제출 모델은 점수를 보지 않는 근거 생성, 근거를 활용한 임베딩 기반 점수
회귀, 초기 네 체크포인트의 예측 평균, 예측 점수 기반 최종 근거 생성으로 구성된다.

핵심 개선은 단일 점수 모델 대신 학습 초반 네 체크포인트의 예측을 평균한 것이다.
이 방법은 별도의 검증 기반 가중치 조정 없이 RMSE와 순위 상관을 모두 개선했다.

다만 결과는 개발 과정에서 이미 사용된 400개 검증 글을 기준으로 하며, 숨겨진 평가
데이터의 성능을 직접 나타내지는 않는다. 근거 품질 역시 사람 평가가 아니라 LLM 평가
결과이므로 참고 지표로 해석해야 한다.
