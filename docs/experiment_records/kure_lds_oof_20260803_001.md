This is a new loss hypothesis, not integration recovery. This draft does not
authorize code execution, GPU use, data generation, refitting, validation
evaluation, or deployment. Label-density smoothing (LDS) is supported by
Yang et al., *Delving into Deep Imbalanced Regression*, ICML 2021
([paper](https://proceedings.mlr.press/v139/yang21m.html),
[official code](https://github.com/YyzHarry/imbalanced-regression)). The
kernel scale and cap below are MAL2026-specific preregistered adaptations, not
values claimed by that paper.

## Frozen single candidate

For every outer fold and axis independently:

1. Use only the 1,600 outer-fit raw axis scores to form a target histogram on
   the exact score grid `1.00, 1.05, ..., 5.00`. Current canonical scores align
   exactly to this grid; runtime must reassert alignment.
2. Smooth counts with a unit-sum discrete Gaussian having physical
   `sigma=0.25` score point, truncated to `|delta| <= 0.50` (21 taps), using
   constant-zero boundaries. No alternative kernel, sigma, truncation, grid,
   or sweep is allowed.
3. At target `y`, let unscaled weight be
   `u(y) = 1 / max(smoothed_count(y), 1e-12)`.
4. Find the unique positive scalar `c` by deterministic bisection so that
   `w(y) = clip(c * u(y), 0.25, 4.0)` has an arithmetic mean of exactly 1 over
   the 1,600 fit examples, within tolerance `1e-6`. This formulation preserves
   both the cap and mean-one contract; post-cap renormalization is forbidden.

The 0.25 scale corresponds to one native rubric increment for organization
and expression, while the +/-0.5 window borrows only from a local ordinal
neighborhood. Inverse smoothed density is the direct LDS weighting mechanism;
the cap limits amplification of the extremely small score-1 groups. Unlike the
already negative effective-number and square-root-sampler candidates, the sole
new factor is local target-density smoothing.

## Training contract

- Backbone: pinned `nlpai-lab/KURE-v1` revision

- Three independent axis models; fresh initialization per outer fold/axis.
- LoRA: rank 16, alpha 32, dropout 0.05, identical Stage3 target modules.
- Phase-1 schedule: 6 epochs, AdamW learning rate `5e-5`, weight decay `0.01`,
  batch 20, gradient accumulation 2, maximum length 1536, deterministic normal
  shuffle, no early stopping, no sampler change, and the same derived Stage3
  `coral-natural` phase-1 seed per outer fold/axis.
- No cRT, calibration, prior correction, ensemble, or second candidate.

For example `i`, rounded ordinal class uses clamped decimal half-up rounding.
The unreduced loss is:

```text
ordinal_i = mean over thresholds k=1..4 of
            BCEWithLogits(z_i,k, 1[y_round_i > k])
raw_i = (CORAL_expected_score_i - y_raw_i)^2
loss = mean_i w_i * (ordinal_i + 0.25 * raw_i)
```

The same fit-only weight is applied once to the complete per-example hybrid
loss. Applying different weights to its two terms, weighting twice, or using a
batch-normalized weight is forbidden. Inference is the natural CORAL PMF
expectation clamped to `[1,5]`.

- complete, finite, exact five-fold coverage and nonzero true low/high support;
- macro RMSE improvement at least `0.005`;

- neither low-tail nor score-5 RMSE worsens;

- macro Spearman drop at most `0.005`;
- lower bound strictly greater than zero for the 95% interval of
  `R0 macro RMSE - candidate macro RMSE` from 10,000 source-ID-clustered
  resamples containing all three axes.

candidate once with no retry, hyperparameter adjustment, or post-result
calibration. Any gate failure permanently freezes the negative candidate,
